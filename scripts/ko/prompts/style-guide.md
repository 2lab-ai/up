# 한국어판 번역 스타일 가이드

## 목표
- 처음부터 한국어로 쓴 책처럼 읽히는 문장. 직역투 금지(‘~하는 것은 ~이다’ 남발, ‘~에 대해’, ‘~를 진행하다’, 이중 피동).
- 원문의 뜻·뉘앙스·논리를 빠짐없이 옮긴다. 요약·생략·추가·해설 삽입 금지. 문단을 합치거나 나누지 않는다.

## 문체
- 본문은 한다체(~다). 독자에게 권할 때도 한다체 명령·청유(~하라, ~해 보자).
- ‘당신’ 남발 금지 — 주어 생략을 우선한다. 원문의 1인칭 ‘\u{6211}’는 ‘나’로 쓴다.
- 표·목록·양식 칸의 짧은 항목은 명사형(~하기, ~함)이나 짧은 한다체로 간결하게 쓴다.

## Frontmatter
- 사람이 읽는 값(title, description, prev.text, next.text, hero/features 문구 등)만 번역한다. 키·link·updated·sources_checked·경로는 그대로 둔다.
- 값에 `: `(콜론+공백)이 들어가거나 YAML 특수문자(- ? : , [ ] { } # & * ! | > ' " % @ `)로 시작하면 값 전체를 큰따옴표로 감싼다. 예: `title: "읽기 안내: 책을 삶으로 돌려놓기"`

## 고유명사
- 중국 인명·지명은 외래어 표기법을 따른다. 현대 인물·지명은 중국어 발음(항저우, 베이징, 선전, 광저우).
- 기업·서비스는 한국 통용명(알리바바 클라우드, 위챗, 타오바오, 빌리빌리, 샤오훙수, 즈후, 더우인).
- 중국 시험·제도는 첫 등장에 짧게 풀어쓴다. 예: 가오카오(중국 대학 입시), CET-4·6(중국 대학영어 4·6급 시험).
- 용어집(glossary)에 있는 항목은 용어집의 한국어를 그대로 쓴다. 제목·장 이름·반복 소제목은 글자 하나까지 용어집과 같게 쓴다.

## 한자·문장부호
- 출력에 한자(\u{6f22}\u{5b57})는 0자. 괄호 병기도 금지. 코드 블록·인라인 코드·파일명·alt 속 중국어도 한국어로 옮기거나 한국어로 풀어 쓴다.
- 책 제목은 한국어판이 있으면 그 제목 『…』, 없으면 번역 제목 『…』(원제가 영어면 영문 원제 병기: 『습관의 힘(The Power of Habit)』). 글·장·기사 제목은 「…」.
- 문장부호는 한국어 규범(, . : ; ! ? ( ) … —). 중국어 전각 부호(，。：；！？、（）【】《》 등)와 전각 문자는 쓰지 않는다. 나열의 ‘、’는 쉼표나 가운뎃점(·)으로 바꾼다. 인용은 “ ”, 인용 속 인용은 ‘ ’.
- 목록 항목 끝의 ‘；’·‘。’을 세미콜론으로 옮기지 않는다. 항목이 문장이면 마침표로, 명사구면 부호 없이 끝낸다. 중국어식 대시 ‘——’는 ‘—’ 하나로 쓴다.
- 날짜·숫자: 2017년 7월, 90일, 3만 자. 날짜 형식 값(2026-09-02)과 수치·단위는 그대로 둔다.

## 그대로 두는 것
- 영어 학습 예문, 어휘 목록의 영어 단어, 코드, 명령어, URL, 경로, 제품명은 그대로 둔다. 그 예문·단어에 붙은 중국어 해설·뜻풀이만 한국어로 옮긴다.
- 코드 블록·표·HTML 속 중국어(설명, 주석, 템플릿 자리표시자, alt·title·aria-label 값)도 번역한다. 구문·태그·속성명·class·id·경로는 바꾸지 않는다.
- 언어 전환 줄의 ‘\u{4e2d}\u{6587}’은 ‘한국어’로 쓴다(예: `한국어 | [English](en/)`). 링크는 그대로 둔다.

## Markdown 구조 1:1
- 제목 수와 레벨, 목록 항목 수, 표의 행·열 수, 코드펜스 수, 인용(>) 줄, HTML 태그, 링크·이미지 대상(URL·경로)을 원문과 똑같이 유지한다.
- 링크 대상(괄호 안 URL·경로와 `#조각`)은 한 글자도 바꾸지 않는다. 한자 조각(`#\u{5de5}\u{5177}\u{4e0e}\u{4ea4}\u{4ed8}` 등)도 그대로 두면 이후 단계가 한국어 제목 앵커로 바꾼다.
- 원문에 없는 번역자 주, 머리말, 저작권·출처 고지, 설명을 덧붙이지 않는다.
