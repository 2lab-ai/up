# 10년 전 블로그 보관함

여기에는 Web Archive에서 복구한 `zb.gs` 옛 블로그의 글을 모았다.

이 글들은 그보다 더 이른 시기에 쓴 것이다. 글쓰기의 꿈이 꺾인 뒤에도 놓지 않은 고집이 있고, 대학 4학년 이후 다시 일을 벌이던 열기가 있고, 사회 문제와 개인의 선택을 두고 내린 소박한 판단도 있다. 이 글들을 이 가이드에 다시 들여놓은 것은 “인생 레벨업”이 방법론에만 머물지 않고, 한 사람이 걸어온 길의 날것 그대로인 단면까지 보여 주게 하려는 뜻이다.

이번에는 접근할 수 있는 Wayback Machine 스냅샷과 글 사이의 상호 링크를 바탕으로 옛 글 4편을 정리했다.

- 2016-04-23: [드디어 글 쓸 곳이 생겼다](a-place-to-write.md)
- 2016-04-24: [작년의 나와 지금의 나를 간단히 소개하며](last-year-and-now.md)
- 2016-04-24: [쓰러진 노인, 도와야 할까 말아야 할까](help-the-elderly.md)
- 2016-05-21: [블로그 임시 이름 변경 공지](blog-renaming-notice.md)

> 일러두기: 원래 사이트의 Archive 색인 인터페이스 일부는 접속이 불안정하다. 여기 적은 날짜는 현재 복구할 수 있는 Wayback 스냅샷을 기준으로 표기했다. 이 보관함은 첫 페이지와 글에 붙은 최근 글 목록에서 복구할 수 있었던 본문과 댓글을 우선 보존한다. 앞으로 옛 글을 더 찾아내면 이 디렉터리 구조에 맞춰 계속 보태 넣으면 된다.
