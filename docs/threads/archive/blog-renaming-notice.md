# 블로그 임시 이름 변경 공지

**편집자 설명(2026-08-31):** 2016년에 올린 이름 변경 공지일 뿐이며, 현재 사이트의 브랜드·서비스·ICP 등록(중국 웹사이트 사전 신고 제도) 상태를 나타내지 않는다. 이름과 링크를 점검해야 한다면 이 책 첫 페이지와 프로젝트 공개 페이지의 현행 정보를 기준으로 삼으라.

> 원문 날짜: 2016-05-21(복구 가능한 Wayback 스냅숏 기준으로 표기)
> 보관 출처: [Wayback Machine 스냅숏](https://web.archive.org/web/20160521100054/http://zb.gs/%E5%8D%9A%E5%AE%A2%E4%B8%B4%E6%97%B6%E6%9B%B4%E5%90%8D%E5%85%AC%E5%91%8A)

이 블로그의 원래 이름은 “병 고치는 고수”다. 최근 보름 동안 ICP 등록에 맞추느라 임시로 생방송 공사로 이름을 바꾸었다. 혼란을 드렸다면 사과한다.
