# 용어와 방법 색인

삶을 용어집으로 바꾸려는 시도가 아니다. 책에서 되풀이해 나오는 말들이 기댈 수 있는 자리를 하나 마련해 둘 뿐이다. 어떤 말의 뜻이 기억나지 않거나 다음에 어느 페이지를 열어야 할지 모르겠다면 여기로 돌아오라.

## 쓰는 법

먼저 지금 마주한 과제를 찾고, ‘정의 → 증거 → 다음 단계’ 순서로 읽어 나가라. 과제를 끝내거나 샘플을 남기거나 더 나은 결정을 내리는 데 도움이 되지 않는 말이라면 굳이 외워 둘 필요는 없다.

## 증거와 판단

| 용어 | 이 책에서의 뜻 | 흔한 오해 |
| --- | --- | --- |
| **기준선** | 도구가 개입하거나 집중 훈련을 하기 전에 저장해 둔 날것의 샘플 | 느낌이나 완성품으로 첫 버전을 대신함 |
| **증거** | 작업물, 녹음, 시험, 출처, 실제 피드백으로 되짚어 갈 수 있는 기록 | 들인 시간, 저장 수, 대화 기록을 능력의 증명으로 여김 |
| **사실** | 출처, 시점, 샘플, 직접 관찰을 짚어 낼 수 있는 내용 | 해석을 이미 입증된 인과로 적음 |
| **해석** | 사실을 이해한 방식. 쓸모 있을 수도 있고 고쳐야 할 수도 있다 | 그럴듯하게 들린다는 이유만으로 점검을 멈춤 |
| **가설** | 다음 행동으로 검증받기를 기다리는 판단 | 바람이나 모델의 답을 결론으로 적음 |
| **추론 경계** | 원문이 분명히 말한 부분, 증거가 뒷받침하는 부분, 스스로 채워 넣은 부분을 구분하기 | 제목, 감정, 단일 사례를 전체 그림으로 여김 |
| **서사 압축** | 복잡한 경험을 한 문장이나 하나의 인과 사슬로 정리해 전하기 쉬운 이야기로 만들기 | 우연, 남의 기여, 알 수 없는 부분을 지운 이야기를 전체 그림으로 착각함 |
| **사후 확신 편향** | 나중에 알게 된 결과로 당시의 선택을 설명하기 | 뒤늦게 나타난 정보를 과거로 거꾸로 밀어 넣음 |

## 한 문장으로 기억하기

순서 하나만 남길 수 있다면 이렇다. 먼저 문제를 분명히 말하고, 기준선을 저장한다. 알맞은 도구로 작은 과제 하나를 해내고, 실제 사람에게 검증받는다. 피드백을 다음 단계에 적어 넣고, 힘이 부족할 때는 먼저 회복한다. 수치심으로 계획을 대신하지 않는다.
